# Toolsy Accessibility Statement

Toolsy is committed to ensuring digital accessibility for people of all abilities. We continuously update our user interfaces to improve the user experience and align with accessibility standards, specifically WCAG 2.1 Level AA.

---

## 1. Conformance Status
The Web Content Accessibility Guidelines (WCAG) define requirements for designers and developers to improve accessibility for people with disabilities. Toolsy is partially conformant with WCAG 2.1 Level AA, meaning some parts of the content do not fully conform to the accessibility standard yet, but core utility functions are optimized for screen readers and keyboard navigation.

---

## 2. Key Accessibility Features
- **Aria Labels**: Interactive controls, buttons, inputs, and form elements contain unique descriptive labels.
- **Keyboard Navigation**: Tool layouts support navigation via tab ordering, allowing users to select inputs, adjust range sliders, and trigger executions without a mouse.
- **Contrast Ratios**: The theme styling utilizes Slate Blue backgrounds and high-contrast Cyan/White typography to meet contrast criteria for low-vision users.
- **Screen Reader Support**: Page structures follow semantic HTML5 outlines, using standard document headings (`h1` through `h6`) to enable clear outline scans.

---

## 3. Assistive Technology Compatibility
Toolsy is designed to be compatible with common assistive technologies and screen readers, including:
- NVDA and JAWS on Windows (Chrome, Edge, Firefox)
- VoiceOver on macOS and iOS (Safari, Chrome)
- TalkBack on Android devices

---
